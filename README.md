# 栖霞游鉴助手

栖霞山移动 H5 游览服务：查看有来源的枫况、查找景点和设施、对照园区导览图，并使用文字伴游。界面采用栖霞秋册的纸本风格，四季配色自动随南京时间变化，也可手动选择。

当前开发基线见 [PRD v1.3](docs/栖霞游鉴助手_开发PRD_v1.3.md)。旧 PRD 和验证记录保留为历史，不作为当前行为依据。

## 已实现

- 首页优先展示官方 **10% 红叶进度**，标明 **2026-10-30** 发布日期和推文来源；另列 **2026-10-31 下午**“大部分叶片绿色、少量微黄”的采风记录。
- 右侧四季配色入口：默认自动，手动选择会保存在本机；按钮、选项卡、背景及滚动条一起变化，业务日期和枫况数据不随配色更改。
- 地图服务上方为实际地图，六类地点图层默认开启；路线偏好和定位按钮在地图下方。支持名称搜索、点选和定位后的直线距离排序。
- 插画赏秋图、园区导览图独立切换，支持缩放、拖动、全屏及横屏优先展示。
- 园区图下方提供“寻茶、寻枫、遛宠”推荐地点；有匹配坐标时跳至实际地图，无坐标时提示查阅园区图。
- 唯一底部导航、加载渐入、枫叶微元素、返回顶部和减少动态效果适配。

## 运行

技术栈：Vue 3 + Vite + TypeScript + Lucide + Leaflet；Node.js + Hono + Zod 单体 API。无需数据库、Redis 或微服务。

需要 Node.js 22+、pnpm 11。

```bash
pnpm install
```

复制 `apps/web/.env.example` 为 `apps/web/.env.local`：

```dotenv
VITE_API_URL=http://localhost:8787/api/v1
VITE_TIANDITU_KEY=你的天地图浏览器端Key
```

```bash
pnpm dev
```

前端 [localhost:5173](http://localhost:5173/)，API 前缀 `http://localhost:8787/api/v1`。环境文件已忽略，不提交实际 Key。浏览器 Key 会进入构建产物，应在服务控制台配置部署域名和配额；生产环境需 HTTPS 才能使用浏览器定位。

## 数据来源与边界

**红叶进度**：[官方枫情预报](https://mp.weixin.qq.com/s/xubdcBQ4x4kGIOf8ucr67A)发布于 2026-10-30 18:13，进度为 10%。它是官方发布快照，既不是实时监测，也不是某个景点的红叶占比。前端采用 7 天展示时效规则，超过时效或进入非秋季后标为历史；保留原始数字，不自动预测新百分比。

**实地采风**：2026-10-31 下午，大部分叶片仍为绿色、少量微黄。没有具体采样点、样本量和精确时间，不补造小时、不换算百分比。

**地图**：天地图提供底图及浏览器 SDK `T.LocalSearch` 检索坐标。用户界面统一称“实际地图”，保留服务署名。官方小程序截图仅提供名称与位置描述，不提供经纬度；目录同名匹配不等于官方坐标核验。只在限定园区范围内显示有效坐标，检索结果去重，未匹配的地点留在目录中。接口有加载、超时、部分失败和重试状态。检索服务覆盖不到的接驳站等设施不补造标记。

**定位**：点击后才申请位置；经纬度仅保存在当前页面内存，用 Haversine 计算并标为“距我·直线”，不作为步行距离或导航。地图服务接收地图浏览范围，地点检索固定园区范围；不会把游客精确位置作为地点搜索参数或写入项目后端。

**推荐与图片**：用户提供的园区折页和两张地图保存在 `apps/web/public/assets/maps/`。参考图不与坐标配准；“千佛崖”与地图目录“千佛岩”的名称差异会提示。携宠区域及运营情况以园区确认信息为准。

## 接口

统一前缀 `/api/v1`，成功响应为 `{ data, meta }`。

| 接口 | 用途 |
| --- | --- |
| GET /bootstrap | 产品、四季主题与功能配置 |
| GET /foliage-context | 官方进度快照与独立采风记录 |
| GET /map | 地图参数与已核验业务数据 |
| GET /pois、/pois/:id | 已发布景点 |
| GET /facilities | 已核验设施 |
| GET /routes、/routes/:id | 已核验路线 |
| GET /maple、/maple/:poiId | 分点位观测 |
| POST /recommendations/routes、/recommendations/maple | 已发布记录的条件推荐 |
| POST /chat | 规则问答与引用 |
| POST /feedback | 尚未开放写入，返回 503 |

## 验证与构建

```bash
pnpm typecheck
pnpm test
pnpm build
```

自动化检查覆盖季节边界、叶色未知值、地理距离、地点筛选与去重、检索部分失败、官方/采风口径、接口空态与反馈不可用行为。地图服务需要联网，自动测试中的隔离数据不会进入游客页面。

2026-11-01 验证：类型检查、16 项测试及生产构建通过；浏览器已确认官方 10%、采风说明、四季切换与刷新保留，实际地图检索成功返回地点。外部检索可能超时，结果包含周边地点，设施分类及目录匹配仍需园区核验，不能视作全量官方设施清单。详见 [本次验证记录](docs/验证记录_v1.3.md)。

前端产物：`apps/web/dist`；后端产物：`apps/api/dist`。后端可执行 `pnpm --filter @maple/api start`，静态站点需单独部署并配置 API 地址。
