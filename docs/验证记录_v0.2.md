# 栖霞山核心 v0.2 验证记录

验证日期：2026-11-01。环境：Windows、Node.js 22、pnpm 11、系统 Edge 无头浏览器；本地 Vite 与 Hono 服务。

## 工程检查

- `pnpm test`：10 项 API 测试通过，覆盖四季配置、路线筛选、设施契约、缺测与有效期、停车和接驳问答。
- `pnpm typecheck`：前后端 TypeScript 检查通过。
- `pnpm build`：前后端构建通过。
- `git diff --check`：无空白错误。
- UI 范式的对比度检查脚本：正文不达标项为 0；装饰色和禁用态不作为正文使用。

## 浏览器验证

| 场景 | 结果 |
| --- | --- |
| 首屏与首 Tab | 默认进入枫况；品牌为“栖霞山核心” |
| 四季主题 | 四套主题色与导语不同；非当前季节有预览提示，可恢复当前季节 |
| 季节时区 | 浏览器设为洛杉矶时区，在上海 3 月 1 日边界仍显示春季 |
| 分点红度 | 有效样例 68%、38%、82%，带进度、日期、来源与有效期 |
| 长开过期 | 模拟跨有效期，当前推荐从 3 条降至 2 条、再至 0 条；不以 0% 代替未知 |
| 天地图 | 浏览器实际取得矢量与中文注记瓦片；服务归属可见 |
| 设施标记 | 3 处厕所、4 处接驳站、2 处停车场，支持分类开关、列表定位和摘要弹窗 |
| 地图复位 | 选择设施放大后可恢复栖霞山视野，关闭旧弹窗 |
| 底图失败 | 阻断天地图请求后显示重试提示，9 个默认设施仍可通过列表查看 |
| 详情切换 | 路线详情后选择景点会清除旧路线；枫况与茶文化入口可打开对应详情 |
| 键盘操作 | 枫况卡和路线卡可用 Enter/Space 打开；关闭按钮具有可访问名称 |
| 移动布局 | 320px、390px 下四季主题和地图无横向溢出，复位按钮可见 |
| 文字伴游 | 接驳问题得到结构化演示回答 |
| 运行错误 | 上述流程未出现浏览器 pageerror |

## 验证边界

底图接入成功不等于业务点位已获园区确认。设施坐标、站序连线、路线和枫况均是演示样例。本次没有验证实际入园导航、真实班次、车位余量、政策权益或正式内容审核后台；上线前输入与验收见 [PRD v1.1](栖霞山核心_开发PRD_v1.1.md)。

天地图浏览器 Key 只保存在本机被忽略的环境文件中，仓库提供空值示例。部署时由项目方设置允许域名和浏览器端环境变量。
