# v0.3 交互与时序验证记录

日期：2026-11-01。对应需求为开发 PRD v1.2；业务点位与红度继续使用演示数据。

## 本轮变化

- 移除顶部重复 Tab，桌面和手机使用唯一底栏；品牌按钮回到枫况。
- 四季按 Asia/Shanghai 月份自动呈现，每 30 秒校时，恢复可见时更新；移除手动主题预览。秋季以枫林谷有效单点观测联动色彩，不计算全山平均。非秋季档案默认收起。
- 用大枫叶与十枚微型枫叶替代条形进度；每叶代表 10%，支持部分填充。叶色由绿经黄转红，保留数字、人工估计和可访问文本。
- 底栏改为枫叶、楼阁、山水游册线描 SVG。补充纸上飘叶、图片淡入、册页入场、页面/抽屉/消息过渡、加载骨架与返回顶部。
- 每 5 分钟尝试更新数据；首次加载有超时和重试；后台失败保留旧数据并继续判断有效期。

## 地图验证边界

本次 Edge 测试环境的外部天地图瓦片请求返回 `net::ERR_CONNECTION_CLOSED`，因此**未确认本轮测试中真实瓦片成功加载**。已确认 Leaflet 初始化与尺寸正常、超时后提示底图暂不可用、3 个厕所及 4 个接驳站标记创建、图层筛选正常，设施列表与路线仍可浏览。真实底图接入方式未改动；最终域名、网络及授权仍需在实际使用环境复核。不能将本轮结果写成天地图在线加载成功。

## 数据边界

颜色与百分比都是演示观测的呈现；自动刷新不等于实时监测。四季规则只是南京日历时序，不预测物候。单点红度不代表全山；历史记录、未知值与过期值不转为当前零值。文化资料、设施坐标、开放状态和线路仍待景区核验。
